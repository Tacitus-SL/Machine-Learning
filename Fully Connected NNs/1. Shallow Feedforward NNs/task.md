# Shallow Feedforward NNs

Build a fully connected classifier for MNIST digits. In `task.ipynb`, prepare the dataset and batches, implement the network's forward pass and loss, then train and inspect its predictions. Follow the notebook's numbered tasks and edit the linked files under `source/code/src/` where prompted.

The checker uses a small offline dataset and one training epoch. For a longer hand run, the notebook uses MNIST and exposes the training settings so you can compare model depth and performance.
