# Shared Source Code

This task holds the Python package used by the fully connected, deep network, and convolutional notebooks. It appears last in the course menu, while each notebook links directly to the file you need to edit.

Start with the notebook for the exercise you are solving, then complete the indicated functions in `src/`. The notebooks check your changes using small offline datasets. The same source files are reused across exercises, so a function you implement once remains available in later tasks.
